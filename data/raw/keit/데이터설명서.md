## 7\. 읽는 법

```python
import pandas as pd
df = pd.read_excel("한국산업기술기획평가원_산업기술 연구개발 과제현황_20260721_정비.xlsx",
                   sheet_name=0, dtype=str, keep_default_na=False)
```

* **`keep_default_na=False` 를 꼭 넣는다.** 이 파일의 결측 표기는 문자열 `N/A`인데, 기본값으로 읽으면 판다스가 `N/A`를 결측(NaN)으로 바꿔 버려 '원본이 비어 있던 칸'과 '코드를 못 붙인 칸'을 구분할 수 없게 된다.
* `dtype=str` 로 읽어야 기관코드가 그대로 보존된다. 기관코드에는 `B552691` 처럼 영문으로 시작하는 값과 `1450000` 처럼 숫자로만 된 값이 섞여 있어, 수로 바꾸면 컬럼이 깨진다.
* 부속 시트는 `sheet_name="기관코드_매핑표"` 처럼 이름으로 지정해 따로 읽는다.
* 참여기관을 행으로 펼치려면 두 컬럼을 같이 나눈다.

```python
org  = df["참여기관"].str.split(",")
code = df["참여기관_기관코드"].str.split(",")
long = df.assign(참여기관=org, 참여기관_기관코드=code).explode(["참여기관","참여기관_기관코드"])
```

* 수치로 쓸 컬럼은 `지원년도` 뿐이다. `과제번호`는 숫자로만 이뤄져 있으나 식별자이므로 문자열로 둔다.
* 날짜로 쓰려면 `pd.to_datetime(df["개발시작일"], errors="coerce")` 처럼 변환한다. `총개발기간`은 한 칸에 두 날짜가 들어 있어 그대로는 변환되지 않는다.
